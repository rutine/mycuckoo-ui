windows tomcat监控(Java 8+), 在catalina.bat加入:
set JAVA_HOME=你的JDK目录
set PATH=%PATH%;%JAVA_HOME%\bin
set JAVA_OPTS=%JAVA_OPTS% -Dcom.sun.management.jmxremote
set JAVA_OPTS=%JAVA_OPTS% -Dcom.sun.management.jmxremote.port=9999
set JAVA_OPTS=%JAVA_OPTS% -Dcom.sun.management.jmxremote.rmi.port=9999
set JAVA_OPTS=%JAVA_OPTS% -Djava.rmi.server.hostname=127.0.0.1
set JAVA_OPTS=%JAVA_OPTS% -Dcom.sun.management.jmxremote.ssl=false
set JAVA_OPTS=%JAVA_OPTS% -Dcom.sun.management.jmxremote.authenticate=false
set JAVA_OPTS=%JAVA_OPTS% -Xms512m -Xmx512m -XX:MetaspaceSize=128m -XX:MaxMetaspaceSize=256m
生产环境建议开启认证与SSL, 不建议直接暴露未鉴权JMX端口。
